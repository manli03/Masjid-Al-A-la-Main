## Masjid A’la 1.3.1

A smoother launch, clearer update progress, and darker backgrounds for more comfortable reading.

### Improvements

- **Clearer app updates:** refreshed update prompts and a collapsible progress card showing download percentage, file size, connection pauses, verification, and installation status.
- **Faster startup and app links:** removed the fixed splash-screen delay, matched the Android launch screen to the app branding, and opened prayer-time links directly in Solat.
- **Better permission timing:** notification and location requests now follow an in-app explanation when you choose the related feature. Permission prompts no longer interrupt startup, and blocked permissions can be managed through device settings.
- **Prayer-time highlighting:** Imsak, Syuruk, and Dhuha now receive the current-time highlight alongside Subuh, Zuhur, Asar, Maghrib, and Isyak.
- **Calmer dark mode:** neutral charcoal backgrounds replace green-tinted surfaces. Amalan now shares the other pages’ background palette while keeping its existing layout.
- **Cleaner Home screen:** hidden the visible scrollbar while keeping scrolling available.

### Fixes and reliability

- Prayer data loads independently of notification permission.
- Opening Solat on a fresh installation waits for the shared prayer-data request within the page, without keeping the splash screen open.
- Returning from notification or exact-alarm settings rebuilds prayer reminders when permission is granted.
- Update checks avoid offering another release while a downloaded update is being verified or handed to Android’s installer.
- Downloads continue to use APK checksum, package, version, and signing-certificate verification before installation.

### Download and install

- Download **app-release.apk** below and confirm the update in Android. Existing users can install it over their current app without uninstalling first.
- Android may ask you to allow installation from the browser or app opening the APK.
- **Android 7.0 or newer · Version 1.3.1 · Approximately 26 MB.**
- `output-metadata.json` is included for compatibility with v1.3.0’s updater; users only need the APK.
