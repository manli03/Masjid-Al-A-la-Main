## Masjid A’la 1.3.0

A refreshed experience for prayer times, daily reading, and keeping your app up to date.
This release includes the changes since the last GitHub release, **v1.1.1**.

### New and improved

- **Refreshed Home, Solat, and Amalan screens** with updated layouts, navigation, and theme styling.
- **Daily wisdom on the home screen** and prayer times available directly from Home.
- **Improved Qibla compass** with more accurate direction handling and a simpler interface.
- **Updates inside the app:** see the new version and download size, choose whether to download,
  and confirm again when the update is ready to install. Downloads show progress and recover
  their status after reopening the app. Choosing “Later” limits reminders to once daily.
- **Manual update checks in Settings**, with downloaded updates ready to install later.
- **Safer update installation** with APK checksum, package, version, and signing-certificate checks.

### Fixes and reliability

- Corrected overnight prayer-time highlighting and improved prayer-time/date handling.
- Improved prayer-notification channels, scheduling, and azan playback handling.
- Improved announcement/comment loading, unread indicators, and scroll behavior.
- Improved authentication token handling and device-specific push-token cleanup on logout.
- Fixed web image sharing and refined dark-mode colors and screen safe areas.
- Improved startup/loading behavior and Android release-build compatibility.

### Download and install

- Download **app-release.apk** below and approve the update in Android. Existing users can
  install it over the current app; use the same installation without uninstalling first.
- Android may ask you to allow installation from the browser or app used to open the APK.
- This version introduces the in-app updater; older versions need this first update through
  the existing download link or the APK below.
- **Android 7.0 or newer. Version 1.3.0, build 9.**
- `output-metadata.json` is included for automatic update checks; users only need the APK.
