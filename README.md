# Mobile App for Mosque Members  
### 🕌 Prayer Reminders & Mosque News @ A’la Mosque  

## 📖 Description  
A dedicated **mobile application** built for the community of **A’la Mosque**.  
The app enhances communication and engagement by providing prayer reminders, mosque announcements, and community updates directly to members’ smartphones.  

## 🔑 Key Features  
- 🕒 **Prayer Time Reminders** – Accurate daily prayer notifications with customizable alerts.  
- 📰 **Mosque News & Announcements** – Stay updated with the latest events, activities, and community programs.  
- 🗓️ **Event & Program Listings** – Highlights upcoming religious classes, gatherings, and special occasions.  
- 👥 **Community Engagement** – Encourages stronger ties between mosque members through accessible information.  
- 📱 **Mobile-Friendly Experience** – Designed with a clean, intuitive interface for easy navigation.  

---

This project reflects a step towards **digital transformation for religious institutions**, leveraging technology to improve accessibility, strengthen communication, and foster a more connected community.
